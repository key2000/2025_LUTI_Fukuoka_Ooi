# employment-centers/

従業中心地（モデルの従業地ゾーン `work_zone`）の選び方を見直すテーマ。

現状は、マスタープランの拠点から人が選んだ18メッシュ（`scripts/Fukuoka_OSM_03_copied.R` L.1780 に
メッシュコードを直書き、`data/work_zone.xdr`）。恣意性を減らすため、データから選ぶ方法を検討する。

## 方針（2026-10-30 時点・未確定）

- 主案：**局所空間自己相関（Local Moran's I、LISA）**で雇用が集まったまとまり（High-High）を抽出し、
  まとまりごとのピークのメッシュを中心地にする。雇用中心の抽出に使った前例がある（Riguelle et al. 2007）。
- 比較案：**閾値法（Giuliano & Small 1991 型）**。密度と規模の閾値を変えた感度分析を添える。
- Getis-Ord Gi\* は一般的なホットスポット分析の手法だが、雇用中心の抽出に使った論文は見つからなかったため、確認用の扱い。

## ファイル

- `references.md` — 文献リスト（雇用中心の抽出手法、Gi\*・LISAの原論文、マニュアル、日本の研究）
- `plan.md` — このモデルに適用するための作業の洗い出しとハードル

試算・試行を始めたら、`NN_短い名前/` のフォルダ（例：`01_lisa-candidates/`）を作って記録する。
