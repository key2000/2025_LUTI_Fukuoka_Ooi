# project_log/planning-history/

福岡都市雇用圏（モデル対象範囲）の都市計画・拠点・交通整備の変遷を調べ、モデルの従業中心地（`work_zone`）や
2009→2021 の雇用分布の変化と定性的に照らし合わせるテーマフォルダ（2026-11-07〜）。未確定の調査メモ。

## ファイル

- `centers_history.md` — 拠点（業務・居住）の位置づけの変遷と、17拠点ごとの開発の経緯、2009→2021 の雇用の増減との対応。
- `transport_history.md` — 交通整備の年表（出典付き）と、拠点ごとの整備と雇用の動きの対応。

## 注意

- 検索は Web 検索と自治体のPDFの本文抽出による。地名とメッシュの対応は座標からの推定を含む（❓で示す）。
- 論文に使う場合は、引用前に原文（計画書の最新版）を確認する。
