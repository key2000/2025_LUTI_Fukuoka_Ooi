# 拠点の変遷と、17拠点ごとの雇用の動き

2026-11-07 作成。未確定。❓＝要確認（推定・記憶による部分）。

## 0. 要点

1. **モデルの従業中心地18か所（除外1つで17）は、福岡県の「福岡都市圏 都市計画区域の整備、開発及び保全の方針（案）」（平成28年）の
   「広域拠点」19か所から、対象範囲外の甘木（朝倉市）を除いたものと一致する**（座標で照合）。
   2026-11-07 ユーザー確認：「マスタープランの広域拠点のうちモデルの対象範囲内のものを雇用拠点にする」という方針で設定したもの。
   博多駅と天神は1つの広域拠点「ＪＲ博多駅/西鉄福岡（天神）駅周辺」なので、モデルでも1拠点（50303302）になっている。
   → 博多駅メッシュ（50303303）の大きな増加が天神の拠点に吸収される理由（`paper-direction/notes.md` 2026-11-07）。
2. つまり今の17拠点は「計画上の拠点」そのもの。2009→2021 の雇用の増減を拠点ごとに見ると、**政策どおりに見える動き**
   （活力創造拠点のアイランドシティ +90%、九大学研都市 +25%）と、**政策と合わない動き**（南部広域拠点の雑餉隈 −8%・大橋 −1%）が混在する。
3. 九州大学の統合移転（2005〜2018）と、跡地のある箱崎・六本松・西新の伸び悩みは整合的に見える。
4. 天神ビッグバン（2015〜）・博多コネクティッド（2019〜）の竣工の多くは2021年以降なので、2021年の経済センサスにはほぼ入っていない（❓竣工年の確認）。

### 読み取り（定性的・暫定）

- **政策どおりに見えるもの**：活力創造拠点（アイランドシティ、九大学研都市）と東部広域拠点（香椎）は全体（+6.7%）より大きく伸びた。
  これらは2009年以前から計画され、2009〜2021年に開発が進んだ場所。
- **大学の移転**：九大の移転先（学研都市、前原）が伸び、移転元（箱崎、六本松、その西隣の西新）は全体より伸びが小さいか減少。
  大学の教職員・学生関連の雇用の移動が見えている可能性がある（産業別の確認が必要 ❓）。
- **政策と合わないもの**：南部の広域拠点（大橋、雑餉隈）は減少。県・市とも拠点に位置づけているが、雇用は集まっていない。
- **都心**：全体とほぼ同じ伸び（+7.1%）でシェアは横ばい。ただし内部では博多駅メッシュが大きく増え、博多駅東メッシュが減った
  （`paper-direction/notes.md` 2026-11-07）。天神ビッグバンの効果は2021年のデータにはほぼ入っていないと考えられる。
- **拠点でない郊外**：新宮町・粕屋町の住宅・商業の成長は、拠点ではなくボロノイの領域として近くの拠点に混ざっている。

### 注意（データ）

- 2009年は経済センサス‐基礎調査、2021年は経済センサス‐活動調査で、調査の方法・範囲が異なる。2009の「全産業」が公務を含むかも未確認（`notes.md` 2026-10-27）。
- 拠点の伸びはボロノイ領域全体の値で、駅周辺の実際の開発範囲とは一致しない。
