# 交通整備の変遷（福岡都市雇用圏）

2026-11-07 作成。未確定。各項目に出典を付けた。❓＝出典が二次情報（Wikipedia系・報道）だけ、または日付が未確定。

モデルの雇用データの時点（2009年7月 経済センサス‐基礎調査、2014年 同‐基礎調査＝現状 scn0、2021年 同‐活動調査）に対して、
各整備が**どの区間に入るか**を「時期」の列に示す。

## 0. 要点

1. **2009〜2014年に、都市圏の骨格になる道路と博多駅の整備が集中した**：
   - 福岡外環状道路の全線開通（2011年4月）
   - 九州新幹線の全線開業とJR博多シティの開業（2011年3月）
   - 都市高速の環状線の完成（2011〜2012年）
2. **2014〜2021年は、都心の公共交通・アイランドシティへの道路・空港が中心**：
   - 都心循環BRT（2016年〜）
   - 空港の民営化（2019年）
   - 都市高速アイランドシティ線（2021年3月）
3. **2021年以降の整備は、2021年の経済センサスには効いていない**：
   - 西鉄の雑餉隈〜下大利の高架化（2022年8月）
   - 地下鉄七隈線の博多延伸（2023年3月）
   - 福岡空港の第2滑走路（2025年3月）
4. **2009年より前**：九大学研都市駅（2005年）と七隈線の開業（2005年）、千早駅（2003年）があり、西鉄宮地岳線の新宮〜津屋崎が廃止された（2007年）。
   2009〜2021年の雇用の動き（学研都市・香椎の伸び）は、これらの整備の数年後の結果として見られる。
5. **モデルの交通網は現在のもの**：道路・鉄道網は OSM から作っており、抽出データの保存日は2026年5月。
   そのため、2009・2014・2021年のどのシナリオでも、**同じ（現在の）交通網**で計算している。
   - 七隈線の延伸などが鉄道網に入っているかは未確認 ❓。
   - 交通網の変化は、モデルの比較には入っていない。雇用分布の効果だけを取り出す設計と整合しているが、論文では明記する必要がある。

### 読み取り（暫定）
- **伸びた拠点の多くは、2009年より前か2009〜2014年に交通の整備があった場所**（学研都市、香椎・千早、前原、姪浜）。
  ただし、九大の移転やアイランドシティのような土地利用の計画と同時に進んでいるので、交通の効果だけを取り出すことはできない。
- **南部（雑餉隈、大橋）は、道路の整備（5号線、外環状道路）があっても雇用は減った**。雑餉隈の鉄道の高架化や空港の機能強化は2021年より後なので、
  2021年の経済センサスにはまだ効いていない。2021年以降の動きを見るには、次の経済センサスを待つ必要がある。
- **都心**：2011年の新幹線と博多駅ビルの効果は、2014年の経済センサス（scn0）に入っている可能性がある。博多駅メッシュの大きな増加
  （`paper-direction/notes.md` 2026-11-07）が2009〜2014年と2014〜2021年のどちらで起きたかは、2014年のメッシュ値で確かめられる。

## 3. 確認すること
- 都市高速の開通日を、福岡北九州高速道路公社の公式資料で確認する（今は Wikipedia 系の情報）。
- 国内線旅客ターミナルの開業日（2020年8月か、それ以外か）。
- モデルの鉄道網（`data/railway_dist.xdr`、OSM 由来）に七隈線の延伸区間が入っているか。入っていれば、モデルの鉄道網は2023年以降の姿。
- バス網の再編（西鉄バス、外環状道路のバス）は今回は調べていない。
