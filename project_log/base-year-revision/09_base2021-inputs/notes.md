# 09 基準年2021・中心地32の入力づくりと再較正（2026-11-08〜）

決定（2026-11-08、README参照）：基準年2021、中心地 17拠点＋単独1万人以上（K=32）、道路の所要時間で集約（感度分析でボロノイも1回）、
賃金は案(c)＋A・B・Sは産業計、GAは今のまま。

## 1. 入力の作成（`scripts/build_base2021_inputs.R`）
出力：`data/processed/centers_<orig17|E20000|E10000|E5000>/inputs_<time|voronoi>.xdr`
（`work_zone_new`, `L_j_hat`, `omega_j`, `L_by_year`（2009/2014/2021）, `omega_by_year`（同）, `assignment`, `share`）。
所要時間行列は 08 の `build_matrices.R`（`centers_orig17/` には今の `data/` の行列をそのまま複製）。

- **中心地**：今の18（`work_zone`）＋2021年に単独E人以上の対象範囲内メッシュ。道路網で孤立する 50302329 は除く（メインと同じ）。番号順に並べる（今の行列と同じ）。
- **集約**：各メッシュから各中心地への道路の時間（link10、`FFtime = linklen/maxspeed`、混雑なし）が一番短い中心地。
  道路でどこにも行けない36メッシュ（孤立メッシュ。居住ゾーンからは除かれているもの）は直線（ボロノイ）で補う。
- **L̂_j(t)**：領域内のメッシュの従業者数（A〜S）の合計。2009＝T000616002、2014＝T000841002、2021＝T001146022。基準は2021。
  - 今のメインとの違い：50302329 の領域の従業者は、今は L̂_j から落ちていた（ボロノイ領域ごと除外）が、新しい作り方では他の中心地に割り当てられる。
    2021の総数は 1,330,482（今の17・ボロノイで 50302329 の領域を除くと 1,305,733）。
- **ω_j(t)**：中心地の領域全体の2021年産業構成（T001157 の従業者数。A・B＝A〜R − C〜R の合計、S＝042）のシェア s_jk と、
  福岡県の産業別賃金 w_k(t)（06、きまって支給する現金給与額、千円/月。A・B・Sは同年の産業計）で
  `ω_j(t) = Σ_k s_jk × w_k(t)`。基準は2021。年ごとの総給与の調整（k_w）はシナリオ側で行う。今のメインの `floor()`（切り捨て）はしない。

## 2. 確かめたこと
- 列の並び：`get_distance_matrix` の戻り値は列が入力順とは限らない。最初の版で中心地の名前を位置で付けたため、前原と九大学研都市の割り当てが入れ替わる誤りがあった。
  列名で対応させるよう修正済み。
- 修正後も、前原（50302176）と九大学研都市（50302290）の ω_j は直線と所要時間で入れ替わる（305↔313）。
  原因は **九大伊都キャンパスのメッシュ 50303117（従業者4,124、うち教育3,227）** が、直線では前原、所要時間では学研都市に入るため。所要時間のほうが自然。
- **賃金の差が小さくなった**：今のメインの ω_j は 305〜355千円/月（中心地メッシュ1つの構成、2022賃金）。
  新しい作り方（領域全体の構成、2021賃金）は 17拠点で 301〜314、32中心地で 301〜321。領域全体で平均すると、どの中心地も産業構成が似てくるため。
  → モデルの中で「どこで働くと給料が高いか」の差が小さくなる。較正結果・シナリオの結果に効く可能性がある（要注意点として記録）。
- 2021年の中心地32の L̂_j の上位：箱崎 50303344（145,253）、50303303（99,843、博多駅 ❓）、二日市 50301491（83,021）、六本松 50302390（70,727）、
  50303301（63,484）、春日原 50302347（62,984）。
