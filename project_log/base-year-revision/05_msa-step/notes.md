## 1. 元のコード（`scripts/Fukuoka_LUTI_model_260617.R` L.1990〜2071 `run_scenario`）

LUTIループの1回の流れ：
1. 今の道路所要時間 `dists_road` から手段選択確率（自転車・自動車・鉄道）を計算
2. 一般化費用 → 可処分所得 → 土地利用の均衡を `nleqslv` で解く（`v_l`, `state`）
3. 自動車ODを道路網に配分（`assign_traffic`、`max_gap = ta_max_gap = 1e-3`）
4. 配分後の混雑した網で新しい所要時間 `dists_road_new` を計算
5. **前回と新しい所要時間を混ぜる**（L.2041〜2043）：

```r
    # MSA averaging for convergence
    diff <- sum((dists_road_new - dists_road)^2)
    dists_road <- msa * dists_road_new + (1 - msa) * dists_road   # msa = 0.5（呼び出し側で固定）
```
6. `diff < tol`（`tol = 100`）か `it > max_iter`（50）で終了

## 2. 何が問題だったか（03 の診断）

- 手順3の道路配分は `max_gap = 1e-3` で打ち切るので、毎回少しずつ違う誤差（雑音）を含む。
- 混合比が **0.5 で固定**だと、毎回の新しい結果の半分がそのまま入るので、雑音は減らずにずっと残る。
  実際、50回回しても `diff` は 13〜310 の間を上下し続け、下がりきらない（03、図2）。
- `tol = 100` はこの雑音の上で止めているだけで、止まる回（3〜5回目）によって結果が変わる。
  その揺れは EV で ±1〜3千万円/月、CO₂ で数 t/日。

## 3. 変更した内容（試験用の関数の中だけ）

```r
    step <- 1 / (it + 1)                                   # 変更点：0.5 固定 → 1/(n+1)
    diff_raw <- sum((dists_road_new - dists_road)^2)       # 元の diff と同じ定義
    dists_road_upd <- step * dists_road_new + (1 - step) * dists_road
    diff_avg <- sum((dists_road_upd - dists_road)^2)       # 平均（混ぜた後）そのものの動き
    dists_road <- dists_road_upd
```

- **混合比 `step` を 1/2, 1/3, 1/4, … と回数とともに小さくした**。1回目は 1/2 なので元のコードと同じ。
  こうすると `dists_road` は「初期値と、それまでの全回の配分結果の単純平均」になる。
  雑音は平均されて小さくなっていく（n回の平均なので、雑音の大きさはおおよそ 1/√n に減る）。
  これが交通分野で本来の意味の MSA（Method of Successive Averages、逐次平均法）で、元のコードのコメントにある「MSA averaging」を、
  混合比を固定せずに名前どおりにしたもの。
- 止め方：`diff_raw`（新しい配分結果と平均の差）は雑音の大きさのまま下がらないので、止める基準には使えない。
  試験では**50回固定**で回し、10・20・30・40・50回目の状態を保存して、結果がどれだけ動くかで収束を判断した。
- それ以外（手段選択・土地利用の均衡・道路配分の設定・鉄道の配分）は元の `run_scenario` と同じ。
  初期値もシナリオ実行と同じ（`dists0.road`、`v_init = results$scn0$v`）。
- 回したシナリオ：現状（scn0、2014の雇用）、2009の雇用、2021の雇用（`scenario_employment_2009_2021.R` と同じ入力）。

## 5. EVの向きによる違いについて（追加でわかったこと）
`ev_benefit(base, scn)` は、基準側（base）の家賃で「効用の差を金額に換算」している。
- A→B を A の家賃で測る＝**等価変分（EV）**、B→A の符号を反転したもの＝B の家賃で測る＝**補償変分（CV）**。
  どちらも経済学で標準の厚生の測り方で、家賃が変わる場合は一般に一致しない。式の誤りではない。
- 2009↔2021 は、ゾーンごとの得失（±数億円/月）が打ち消し合って合計が小さいので、家賃の重みの少しの違いで合計が大きく変わる。
- → 論文では EV と CV の両方を示す（どちらを主にするかはユーザーの判断、`decisions_2026-11-08b.html`）。
