## 1. 2014をシナリオ手順に通すと scn0 と同じになるか
- scn0 自体が `run_scenario` で計算されており（入力は2014の L̂_j と ω_j そのまま）、2014を同じ手順に通しても入力は同一（倍率1）。
  → 「scn0 だけ別の手順」という仮説は外れ。

## 2. LUTIループの収束
- tol=1 にすると50回回しても収束しない。道路所要時間の変化量 diff は 13〜80 の間を上下し続ける（scn0・2009・2021とも）。
  → 道路配分（max_gap=1e-3）の打ち切り誤差による**雑音の床が diff≈10〜100** にあり、今の tol=100 はその床の上で止めているだけ。
- 雑音によるEVの揺れ：
  - scn0（tol=100）と scn0（50回）の差：**−2,578 万円/月**
  - 2009（tol=100）と 2009（50回）の差：**+893 万円/月**

## 読み取り
- 現状比の大きなEV（+3.5〜4万）は収束の甘さでは**説明できない**（厳しくしても残る）。
- 一方、**2021−2009 のEV（約−2千）は、雑音の大きさ（±1〜3千）と同程度**で、符号も含めて意味のある差とは言えない。
  CO₂の差（+0.4%）も、雑音で数tCO₂/日ぶれる（scn0のCO₂合計 6,206.5 vs 6,204.6）。
- 現状比EVが2009・2021の両方で大きな正になる原因は未解明 → `diag_ev2.R` で、逆向きのEV（2009→現状）・2009と2021の中間の分布・従業ゾーン別の寄与を調べる。
- 論文に向けて：雑音の床を下げるには道路配分の max_gap をさらに小さくする（計算時間増）か、複数回の平均を取る必要がある。小さな差を議論する以上、必須。

## 4. 追加の診断（`diag_ev2.R`、tol=100）
### EVの向きを逆にしたとき（万円/月）
| A→B | EV(A→B) | EV(B→A) | 和（0なら整合） |
|---|--:|--:|--:|
| 現状(2014)↔2009 | 37,382 | −34,623 | +2,759 |
| 現状(2014)↔2021 | 32,121 | −25,067 | +7,054 |
| 2009↔2021 | −2,006 | +13,710 | +11,704 |
| 現状→2009と2021の中間 | 34,302 | | |

- 現状比の大きなEVは、逆向きでもほぼ符号が反対になる → **計算上の誤りではなく、モデルの中で「2014の分布は2009・2021より厚生が低い」と出ている**。
- 一方、2009↔2021は逆向きにすると −2,006 と +13,710 で、和が +1.2万。符号（2009の方が良い）は一致するが、**大きさは近似の誤差（基準側の家賃で評価する式のため）で大きくぶれる**。EVは片方向だけでなく両方向とその平均で示す必要がある。

### 従業ゾーン別の寄与（現状→2009 / 現状→2021、万円/月）
- 最大の正の寄与：**50303344（箱崎・博多駅東側を含むゾーン）**：+34,449 / +40,597。2014の L̂_j が 150,825 と、2009（144,653）・2021（143,412）より6〜7千人多い。
  ここの雇用が減ると v_j（そのゾーンで働く世帯の効用水準）が 121.0 → 122.0〜122.2 に上がり、人数が多いので寄与が大きい。
- 都心 50303302 は雇用が増えて v_j が下がり、負の寄与（−19,912 / −27,929）。
- v_j のゾーン間の差が大きい（都心 98 〜 アイランドシティ 215）。数千人の移動で数億円/月の差が出るのはこの勾配のため。

## 結論（t21）
- EVの違和感の正体：**2014の雇用分布だけ 50303344 ゾーンに雇用が6〜7千人多く、モデルはそこで働く世帯の厚生が低い（住宅が逼迫）と評価する**。2009・2021はどちらもそこから雇用が減るので、現状比で同じ向きの大きなEVが出る。数値計算の誤りではない。
- ただし v_j の勾配そのものが、較正の不整合（雇用2014・世帯2020）で k_i が歪んだ結果である可能性がある → 基準年2021での再較正後に再確認。
- 付随する問題：(1) 収束の雑音でEVが±1〜3千ぶれる、(2) EVの近似式は向きで大きさが変わる（2009↔2021で 2千 vs 1.4万）。論文で小さなEVの差を論じるなら、両方とも対処が必要。
