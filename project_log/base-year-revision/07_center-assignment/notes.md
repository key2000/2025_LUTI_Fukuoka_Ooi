# 07 中心地への集約：直線距離（ボロノイ）と所要時間の比較（2026-11-08）

ユーザー決定（2026-11-08）：中心地は「今の17拠点＋2021年に単独で1万人以上のメッシュ」（K=32）を主、2万人（K=24）・5千人（K=46）を感度分析。
あわせて「ボロノイ分割（直線距離）と所要時間で区切った場合で、割り当てがどれだけ変わるか、ざっと確かめる」。

- スクリプト：`voronoi_vs_time.R`（集計）、`voronoi_vs_time_detail.R`（差の大きいメッシュ）。結果 `voronoi_vs_time.rds`。
- 所要時間：道路網 link10 の混雑なしの時間（FFtime）で、各メッシュ → 各中心地の最短時間。一番短い中心地に割り当てた場合と、今のボロノイ（メイン L.279〜305 と同じ作り方）を比べた。
- 雇用：経済センサス活動調査 2021（T001146022、A〜S）。

時間差＝「ボロノイで割り当てた中心地までの時間 − 一番近い中心地までの時間」。

- 変わったメッシュの7割（E=1万で151のうち109）は、時間差が5分以下。境界の近くで、どちらに割り当てても大差ない。
- **10分以上違うのは14〜18メッシュ（従業者 約0.9〜1.4万人）**。最大の例は、博多湾の北側（海の中道・志賀島の方向 ❓）のメッシュが、
  直線では湾の向こうの姪浜・西新側に割り当てられ、道路では アイランドシティ に近い（時間差 56〜62分）。**直線距離が海を越えている**明らかなずれ。
- 今の17拠点では、天神の西隣の大きなメッシュ 50303301（63,484人）が、所要時間だと六本松に移る（天神から六本松 7.6分）。
  E=1万ではこのメッシュ自体が中心地になるので、この問題は消える。
- 中心地ごとの従業者数（E=1万）：差が大きいのは 箱崎 50303344（直線 82,980 → 時間 144,640、+74%）、50303314（−60%）、六本松（+57%）、西新（−47%）。
  都心周辺の中心地どうしは数分の差で取り合うので、どちらの方法を使うかで各中心地の L̂_j が大きく変わる。

## 読み取り
- 境界付近の「数分差」の入れ替わりは、どちらの方法でも正解とは言えない（実際の勤め先は各メッシュ内にある）。
- 海を越える割り当て（約1万人）は、直線距離では明らかに不自然。所要時間で区切れば直る。
- 所要時間は道路（自動車・混雑なし）だけで測っている。都心は鉄道通勤が多いので、「道路で近い」が最適とも限らない。
- → どちらにするかはユーザー判断（`decisions_2026-11-08c.html`）。
