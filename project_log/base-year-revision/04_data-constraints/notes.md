# 04 賃金・雇用データの制約の調査（t18、2026-11-07）

Web調査（ページ閲覧のみ、ダウンロードなし）。「確認済み」は出典ページで確認、「未確認」は推測を含む。

## 雇用（経済センサス）
- **対象範囲（確認済み）**：2009・2014基礎調査のメッシュ集計は国・地方公共団体を含む。2021活動調査の T001146 は
  「A〜S全産業」と各大分類が国・地方公共団体を含み、「A〜R（S公務を除く）」は民営のみ（T001146 の項目定義の注記）。
  → **3時点とも A〜S（T000616002 / T000841002 / T001146022）で範囲はそろう。今のシナリオの列の選び方で正しい**。
  （02で「公務を除くと+0.9%」としたのは、2021だけ公務を除いた比較で、範囲がそろっていない）
- **ただし（確認済み）**：2021年は国税庁法人番号公表サイトの情報で名簿を拡充しており、従来より幅広く事業所を把握 → 単純比較は不可と統計局が注意。
  2009→2021の総数 +6.7% には、把握範囲の拡大が混ざる。分布（シェア）の比較でも、新たに把握された小規模事業所の分布が混ざりうる。論文に注記が必要。
  出典：https://www.stat.go.jp/data/e-census/2021/kekka/pdf/k_riyou.pdf 、https://www.stat.go.jp/data/mesh/pdf/r3gaiyo.pdf
- **2009・2014の1kmメッシュ産業別（確認済み）**：e-Stat 統計GISの T000616・T000841 は全産業の事業所数・従業者数のみ。
  統計局のメッシュ集計自体には産業別（表番号092〜259）があるが、e-Statでは公開されておらず、入手方法・費用は未確認（統計局へ問い合わせが必要と推測）。
  出典：https://www.e-stat.go.jp/help/data-definition-information/shuroku/T000841.pdf 、https://www.stat.go.jp/data/mesh/pdf/h26keisenkiso.pdf
- 代替：2014は町丁・大字別 T000843（産業大分類A〜S、e-Stat公開）を面積按分。2009の町丁別は未確認。2016活動調査の1kmメッシュ産業別はe-Statにある（国・地方公共団体は対象外、未確認）。
- 産業分類：2014は第13回改定（確認済み）、2009は第12回改定（推測）。大分類A〜Sの見出しは3時点で同じ。

## 賃金（賃金構造基本統計調査）
- 平成21・26年、令和3年の都道府県別・産業大分類の表がe-Statにある（確認済み。所定内給与などの項目がそろっているかは未確認）。
  出典：https://www.e-stat.go.jp/stat-search/files?toukei=00450091&tstat=000001011429
- 2020年（令和2年）から推計方法が変わった（復元倍率に回収率の逆数を掛ける、雇用形態別に復元 など、確認済み）。
  新方式での遡及値は平成18年分まで参考値で公表されているが全国の表のみで、**都道府県別の遡及値は未確認**。
  → **2026-11-08訂正：都道府県別の遡及値（都道府県別第1表、平成18年〜令和元年）も公開されていた**。06でダウンロード済み。
  出典：https://www.mhlw.go.jp/toukei/itiran/roudou/chingin/kouzou/detail/sokyu.html
- 対象は16大産業で、農林漁業（A・B）と公務（S）は含まれない（推測）。メッシュ側のA・B・Sは全産業平均などで補う必要。
  今の ω_j は「A〜R」の構成と産業C〜Rの賃金で計算しているので、この扱いと整合（A・Bは含まれていない点は要確認）。
- 実質化：消費者物価指数（福岡市）。年次の比なので基準年（2020/2025）の違いは結果に影響しない。
