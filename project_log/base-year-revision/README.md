## 決定事項（2026-11-08、ユーザー。判断材料は `decisions_2026-11-08.html`）

   変更は 05 の notes.md に「どこを・なぜ・どう変えたか・変える前と後の結果」を詳しく記録する。

## 決定事項（2026-11-08 その2、判断材料は `decisions_2026-11-08b.html`）
1. 案Cをメインに導入：混合比 1/(n+1)・40回固定。`msa = 0.5, tol = 100` を渡せば元のやり方に戻る（05 の notes.md 7節）。
2. GA（較正）のループは今のまま。較正後に、そのパラメータで scn0 を案Cで回し、fitness の違いを1回確認する。
3. 厚生は基準年（scn0）の家賃で測るEVを主、CV（シナリオ側の家賃）を参考。シナリオ間の差は「EV(基準→A) − EV(基準→B)」。
4. 中心地は 17拠点＋2021年に単独1万人以上（K=32）を主、2万人（24）・5千人（46）を感度分析。集約方法の比較は 07。
5. 賃構にない A・B・S は、同じ年の福岡県「産業計」の賃金で補う（t24で実装）。
