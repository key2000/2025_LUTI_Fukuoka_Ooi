# project_log/paper-direction/

論文としてまとめる方向性・先生とのやり取り・次のTODO・素材の下書きを置くテーマフォルダ。
**まだ論文に載せると決めていないものは全てここ（または他の `project_log/` テーマ）に置く。**
論文に載せると決めた内容だけが `paper/` に昇格する（`paper/README.md`、スキル `promote-to-paper`）。

## ファイル

- `notes.md` — 論文の方向性、指導教員とのやり取り、次のTODOを日付順に追記するメモ。NNフォルダ運用はせず、
  このファイルに追記していく（`project_log/scenario-analysis/plots/note.md` と同じ方針）。
  モデル改良の動機（例: Stone-Geary型効用関数の検討）もここ。作業の前提となる方針を確認したいときに読む。
- `ch3_ch4_materials.md` — 第3章（研究方法）・第4章（分析結果）の節立てに沿って、式・パラメータ・データ・図・数値の
  所在と、未記録の値（⬜）・要確認点（❓）を整理した素材の下書き。**未確定を含むので `paper/` ではなくここに置く。**
  論文の該当節を書く、または図・数値が増えたときはここを更新し、採用が決まった項目だけを `paper/` に昇格する。

## 記録するとき

- 先生の返信・方針変更・新しい検討事項は `notes.md` の末尾に日付見出し（`## YYYY-MM-DD`）で追記する。
- 「論文に採用する」と決まったら、ここに書かずスキル `promote-to-paper` を使う（採用の判定はユーザー）。
  昇格した項目の `notes.md` 側の記述は、経緯として残してよい（削除しない）。
