### 3.1.2 家計の行動

> → 論文採用済み（2026-09-19、paper/ch3_method.md の 3.1.2）。下の ❓ は採用内容に含めていない未確定事項として残す。

**書くこと**: 効用最大化 → 床面積需要・付け値地代、そして通勤の一般化費用（手段選択）。

**効用最大化（Cobb-Douglas）** ✅ 本体 L.478, L.515
- 効用 $U = z^{\alpha_z} a^{\alpha_a}$、予算 $z + r\,a = Y_{ij}$、
  可処分所得 $Y_{ij} = \max(\omega_j - c_{ij},\, 0)$（従業地賃金 − 通勤費用）。
- 床面積需要 $a_{ij} = \alpha_a Y_{ij}/r_{ij}$（コード `a_fij_H`、式9）。
- 間接効用 $v = \alpha_0 Y_{ij} / r_{ij}^{\alpha_a}$、$\alpha_0=\alpha_z^{\alpha_z}\alpha_a^{\alpha_a}$。
- 従業地 `j` の労働者の効用が均衡水準 $v_j$ に等しい（居住地 `i` によらず）という条件から、
  **付け値地代** $r^H_{ij} = (\alpha_0 Y_{ij}/v_j)^{1/\alpha_a}$（式11、コード `r_ij_H`）。
- 指摘点（Stone-Geary検討の動機）: Cobb-Douglasでは所得が増えると床面積需要が比例的に増え続け、
  実データより床面積が過大になる（→4.1、`project_log/paper-direction/notes.md`）。

**通勤の一般化費用** ✅ 本体 L.665–676（LUTIループ内）、L.604–610
- 3手段ロジット（bike＝徒歩・自転車、car＝自動車・二輪、rail＝鉄道・バスを集約）：
  - $V_{bike}=\beta_t T_{bike}$
  - $V_{car}=\beta_t T_{car}+\mathrm{ASC}_{car}+\beta_p\,(P^{park}_o+P^{park}_d)/2$
  - $V_{rail}=\beta_t T_{rail}+\mathrm{ASC}_{rail}$
- 平均一般化費用 $\mathrm{agcc}_{ij}=\sum_m P_m V_m/\beta_t$（分）、$c_{ij}=1.6\times\mathrm{agcc}_{ij}$（千円/月）。
  ❓ ログサム（期待最大効用）ではなく**選択確率加重平均**を使っている点を論文で明記するか、ログサムに直すか要検討。
- 推定値 ✅（`data/result.mc02.xdr`、MC L.428–505）

  | 変数 | 推定値 | 標準誤差 | z |
  |---|---|---|---|
  | 所要時間 β_t（/分） | −0.05255 | 1.81e-4 | −291 |
  | 自動車定数 ASC_car | 1.1177 | 4.33e-3 | 258 |
  | 鉄道定数 ASC_rail | −0.2702 | 3.38e-3 | −80 |
  | 駐車料金 β_p（/円/日） | −0.002437 | 5.82e-6 | −419 |

- 推定データ ✅: 第5回北部九州圏パーソントリップ調査（H29）の通勤目的・代表交通手段別OD交通量。
  PTゾーン内で世帯数最大メッシュを出発点の代表とし、ネットワーク上の所要時間を説明変数に用いる
  （MC L.60–150）。❓ 到着点の代表も、コード上は世帯数最大メッシュ（`tI4`）が使われていて、従業者数最大メッシュ
  （`tI5`）は計算されているが未使用。意図どおりか確認する。
  ⬜ McFaddenの疑似R²は `MC` L.532（4変数版）で計算されるが値は記録されていない。
- ❓ 限界の明記: 鉄道網にバスは含まれない（バスは「rail」手段に集約されている）。中心部で自動車が過大だったため
  駐車料金を追加した経緯がある（MC L.431 のコメント）→ 手法の説明に使える。

### 3.1.3 デベロッパーの行動

> → 論文採用済み（2026-09-19、paper/ch3_method.md の 3.1.3）。下の ❓ は採用内容に含めていない未確定事項として残す。

**書くこと**: 床面積の供給（生産関数・利潤最大化）、従業地別の入居者配分。

**床面積供給** ✅ 本体 L.492–499
- 生産関数（コードの式14・15と整合する形）$F = \gamma_0\,K^{\gamma_1} G^{1-\gamma_1}$（`K`は建設投入、$k_i$はその単価）。
  平均家賃 $\bar r_i$ のもとでの利潤最大化により、
  $F_i = \gamma_0\left(\dfrac{\bar r_i\gamma_0\gamma_1}{k_i}\right)^{\frac{\gamma_1}{1-\gamma_1}}G_i$（式14、`A_Fi_S`）。
- デベロッパーが土地に支払える付け値
  $rg_i=\phi(1-\gamma_1)(\bar r_i\gamma_0)^{\frac1{1-\gamma_1}}\left(\dfrac{\gamma_1}{k_i}\right)^{\frac{\gamma_1}{1-\gamma_1}}$（式15、`rg_i`）。
  ❓ 式の導出はコードの式から逆算したもの。論文に載せる前に、元の式（先生の資料）と突き合わせる。
- 容積率 $FF=F_i/G_i$、階数 $=FF/\phi$、建物高さ $=$ 階数 × 3m（本体 L.501–507）。

**床面積の従業地別配分（入居者の選択）** ✅ 本体 L.481–485
- 居住ゾーン `i` の床面積が従業地 `j` の世帯に貸される確率を付け値地代のロジットで与える：
  $P(j|i)=\exp(\theta_H r^H_{ij})/\sum_{j'}\exp(\theta_H r^H_{ij'})$（式12）。
- 平均家賃（帰属地代）$\bar r_i=\sum_j r^H_{ij}P(j|i)$（式13）。
- ❓ この配分を3.1.3（貸し手＝デベロッパーの選択）と3.1.5（均衡）のどちらで説明するかは構成の好み。

**パラメータ** ✅: $\gamma_0,\gamma_1,\theta_H$ は較正（→3.3）、$\phi=0.5$ 固定、$k_i$ は現状 0.1 固定（→3.3）。

**図表候補**: 建物高さ・容積率の分布図（`Hi_df`、`landuse/scenario_building_height_diff_maps*.png` は差分のみ。現状の高さ分布図は未保存）。

### 3.1.4 土地所有者の行動

> → 論文採用済み（2026-09-19、paper/ch3_method.md の 3.1.4）。下の ❓ は採用内容に含めていない未確定事項として残す。

**書くこと**: 農地から宅地への転用（土地供給）。

- 可住地面積 $G0_i$（→3.2・3.3）のうち宅地に供される面積 $G_i$ を、デベロッパーの付け値 $rg_i$ と
  農地地代 $rr_a$ の差に対するロジット（弾力性 $\theta_L$）で決める ✅ 本体 L.495–496：

  $G_i = G0_i\dfrac{\exp\{\theta_L(rg_i-rr_a)\}}{1+\exp\{\theta_L(rg_i-rr_a)\}}\;\phi_{pub}\,\phi$
- 土地所有者の地代収入 $GI_i = rg_i G_i + (G0_i-G_i)\,rr_a$（千円/月、本体 L.2490–2492、評価指標→3.5）。
- ❓ $\phi_{pub}=0.6$（公共空間）と $\phi=0.5$ が $G_i$ に乗じられる意味づけ（宅地として使える割合か）を
  元の式と照合して文章化する。
- パラメータ $\theta_L$ は較正（→3.3）。

### 3.1.5 市場均衡条件

> → 論文採用済み（2026-09-19、paper/ch3_method.md の 3.1.5）。下の ❓ は採用内容に含めていない未確定事項として残す。

**書くこと**: 均衡の定義、未知数・方程式、解法、LUTIループの収束条件。

**土地利用の均衡** ✅ 本体 L.517–523, L.541–550
- 床面積供給 $A^S_{ij}=F_iP(j|i)$（式17）と需要 $l_{ij}a_{ij}$ の一致から
  $l_{ij}=A^S_{ij}/a_{ij}$（式18、居住 `i`・従業 `j` の世帯数）。
- 従業地 `j` の世帯数が従業者数に一致：$\sum_i l_{ij}=\hat L_j$（式19）。
- 未知数は従業地別の均衡効用 $v_j$（17個）、方程式も17本。`nleqslv`（`global="dbldog"`、
  `ftol=xtol=1e-8`）で $\log v_j$ について解く。初期値 $v_j=270$。

**交通との反復（LUTIループ）** ✅ 本体 L.800–878、`run_scenario()` L.1389–1477
1. 現在の所要時間で手段選択 → 一般化費用 → 可処分所得。
2. 土地利用均衡を解く → 自動車OD $= l_{ij}\times P^{car}_{ij}$。
3. 道路網に利用者均衡配分（`cppRouting::assign_traffic`、`bfw`、`max_gap=1e-2`）。
   BPR関数 $\alpha=0.48,\ \beta=2.89$（山田・松井 1998）、容量は道路種別ごと（pcu/h、国総研資料）を
   K値0.1で日単位相当に換算（`cap/KK`）。
4. 混雑後の所要時間行列を MSA（平滑化係数0.5）で更新。所要時間行列の変化の二乗和 <100 で収束
   （本体ループ上限1000回、`run_scenario` は上限50回）。
5. 鉄道は混雑を考慮せず、均衡収束後の最終状態に対して1回だけ配分（世帯/日）。
