## 0. 用語（このファイルで使う言葉）

| 用語 | 意味 |
|---|---|
| **均衡** | 全員が「これ以上動いても得をしない」状態。都市モデルでは、家賃・立地・交通量が互いに整合した状態を解く |
| **単一中心モデル**（monocentric） | 雇用がすべて都心（CBD）1点にあり、家計は都心からの距離だけで住む場所を選ぶ、という単純化をした都市経済学の基本モデル（Alonso–Muth–Mills） |
| **付け値地代**（bid rent） | ある場所に住むために家計が払ってもよい最大の家賃。最も高く付けた人がその土地を使う |
| **LUTIモデル** | Land Use–Transport Interaction。土地利用（どこに住み・働くか）と交通（どう移動するか）を相互に影響させて解くモデルの総称。実務で使う「操作型（operational）」モデルを指すことが多い |
| **空間相互作用モデル** | 「出発地の量×目的地の量÷距離の関数」で地域間の流動を表すモデル（重力モデル）。Lowryモデルや多くの初期LUTIの土台 |
| **CUEモデル**（応用都市経済モデル） | 日本で発達したLUTIの系統。家計・企業・地主の効用・利潤最大化と土地市場の均衡から立地と地代を決め、交通モデルとつなぐ。便益を経済学的に整合的に測れるのが売り |
| **CGEモデル**（応用一般均衡モデル） | 家計・企業・政府の行動と、財・労働・資本などすべての市場の需給一致を同時に解くモデル。**空間CGE**はこれを地域・ゾーンに分けたもの |
| **定量空間モデル**（QSM） | 都市経済学で2015年ごろから主流。家計の居住地・就業地選択が「通勤の重力式」になる簡潔なモデルを、実データに**ぴったり一致**するように較正し（モデルの逆算＝inversion）、反実仮想を計算する |
| **集積の経済** | 人や企業が集まるほど生産性（賃金）や住み心地が上がる効果。QSMやCGEでは内生的に入れることが多い |
| **エージェントベース／マイクロシミュレーション** | 世帯や個人を1人ずつ（1世帯ずつ）表して、選択を個別にシミュレーションするモデル |
| **利用者均衡配分**（UE） | 全ドライバーが「自分の経路の所要時間はこれ以上短くできない」状態になるように道路網に交通量を流す方法（Wardrop均衡） |
| **反実仮想**（counterfactual） | 「もし〇〇だけが違っていたら」を、モデルで計算した仮想の状態 |
| **等価変分（EV）** | 政策の前後の効用の差を、お金（所得）に換算した厚生の指標 |
| **構造推定・識別** | パラメータを、偶然に近い外生的な変化（例：ベルリンの壁）を使ってデータから統計的に推定すること。GAで適合度を最大化する較正とは考え方が違う |

## 4. 私のモデルの強みと弱み（系統別）

### 4-1. 全体を通した強み
1. **土地利用の均衡（家賃・床面積が内生）＋3手段選択＋実際の道路網への利用者均衡配分＋交通CO₂と住宅CO₂＋EV**が1つのモデルにそろっている。
   各要素は既往研究にあるが、全部そろった例は各系統で少ない（とくにQSMにはCO₂がほぼ無い。CGEは道路網が粗い）。
2. 1kmメッシュとOSM道路網という**細かさ**（CUE・CGEとしては細かい部類）。
3. 公的統計（住宅・土地統計調査、経済センサス、国勢調査、PT調査）だけで作れる → 日本の他都市へ同じ手順で移せる可能性（`project_log` の multi-city 整理と関係）。
4. 2009/2021 の**観測された雇用分布**を入力にし、総数・総賃金を固定して「分布の効果だけ」を取り出せる設計。

### 4-2. 全体を通した弱み（査読で突かれやすい順）
1. **雇用と賃金が外生**：雇用の再配置が生産性（集積）を通じて賃金を変える効果が入らない。QSM・CGE側の査読者はまずここを聞く。
   → 対策：「生産性を固定し、通勤・住宅市場の経路だけを取り出す」設計として明示し、限界に書く。可能なら賃金に簡単な集積弾力性（例：Ahlfeldt 他 2019 の推奨値）を入れた感度分析。
2. **家計が1種類**：所得層・世帯人数の違いがなく、分配（誰が得をするか）を言えない。Herzog・Barwick・Delventhal は分配を主張の柱にしている。
3. **パラメータの識別**：GAで適合度を最大化しているだけで、外生的な変化による識別ではない。QSMの標準からは弱い。
   → 対策：k_i を「観測された居住分布を再現するアメニティの逆算」（QSMの inversion と同じ考え方）と位置づけ、Yamamoto 他 (2019) の調整係数の議論とつなぐ。01 vs 07 の頑健性（G3）を示す。
4. **従業ゾーンが17**と粗い（居住側847と非対称）。都心内の雇用の入れ替わりが消える（`employment-centers/plan.md`）。
5. 鉄道・自転車の混雑なし、通勤以外のトリップなし、静学。
6. 観測された変化（2009→2021の実際の居住・交通量の変化）でモデルを検証していない。QSM系の雑誌では検証が求められやすい。

| CUE（Ueda 2013, 武藤 2021, Liao 2026） | 1kmメッシュ×OSM網の細かさ、GAによる較正、住宅CO₂ | CUEの多くは企業立地・業務用地も内生。私のモデルは雇用・賃金を外生にしている。**同じ系統なので「CUEとして新しい仕組み」は言いにくい** |
| 都市CGE（RELU-TRAN, MOLES） | 空間の細かさ、道路網配分の詳しさ、計算の軽さ | 労働・財市場、企業立地、産業連関、財政。雇用の再配置をモデルの中で起こせない |
| QSM（Ahlfeldt, Allen & Arkolakis, Mann 2026） | **CO₂（交通＋住宅）**、床面積供給の内生化、PT調査で推定した手段選択 | 集積・内生賃金、構造推定による識別、データへの完全一致、観測された変化による検証、分配 |

## 5. 新規性への示唆（`literature_gap.md` への反映候補）

1. **モデルの仕組みそのもので新規性を言うのは難しい**。私のモデルはCUEの範囲内で、各要素（均衡・手段選択・UE配分・CO₂・EV）はどれも既往にある。
   → 新規性は「**問い（観測された雇用再配置の効果）×評価の組合せ（厚生＋交通CO₂＋住宅CO₂を経路別に）**」で言うのが現実的（G1の方針は変わらない）。
2. **G1の根拠を修正する必要がある**：「QSMは混雑配分を持たない」は、Allen & Arkolakis (2022)、Herzog (2024)、Barwick 他 (2021)、Mann 他 (2026) があるので言えない。
   言い換え案：「混雑・手段選択を入れたQSMは増えているが、**CO₂（とくに住宅側）を評価したもの**、および**観測された都市圏内の雇用分布の変化だけを反実仮想として与えたもの**は見つからない」。
3. QSMの「観測された変化を使う」考え方（Ahlfeldt 2015、Heblich 2020）と、CUE/LUTIの「交通とCO₂の詳しさ」の**橋渡し**として位置づけると、
   両方の読者に説明しやすい（Mann 他 2026 が交通系雑誌 *TR Part A* に載っているのは、この橋渡しが受け入れられる前例）。
4. G3（較正データの選択）は、Hörcher 他 (2026) が厚生の統計的不確実性を定量化しているので、「較正の不確実性」一般ではなく
   「**データ源の選択（民間物件データ vs 公的統計）**」に絞って言う必要がある。
5. 弱み1（雇用・賃金の外生）は、G1の設計（分布だけを動かす）と表裏一体。「集積効果を入れない＝通勤・住宅の経路の純粋な効果」と書けるが、
   集積の感度分析を1本入れると査読への備えになる。
