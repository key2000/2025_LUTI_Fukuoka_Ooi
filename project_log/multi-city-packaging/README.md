# project_log/multi-city-packaging/

福岡以外の都市・複数シナリオに同じLUTIモデルを使えるようにするため、モデル本体（共通）と
都市・シナリオ固有の設定を分離し、将来的にRパッケージ化するための計画・記録を置くテーマフォルダ。

方針（2026-10-29時点）：リポジトリは都市ごとに分けず1つのまま、`R/`（モデル共通関数）・
`cities/<都市>/`（都市設定・前処理）・`scenarios/`（シナリオ定義）に分ける。パッケージ化は
その後、`R/` を切り出す形で行う。
