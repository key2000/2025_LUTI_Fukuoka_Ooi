# 第3章 研究方法

採用範囲: 3.1 構築するモデル、3.2 分析対象、3.3 のうち使用データと固定パラメータ。
未採用: 3.3 のキャリブレーション、3.4 シナリオの内容、3.5 評価指標（`project_log/` で継続）。

## 3.1 構築するモデル

### 3.1.1 モデルの概要と仮定

- 採用日: 2026-09-19
- 根拠: `scripts/Fukuoka_LUTI_model_260617.R`（`caluculate_model_state()`、LUTIループ）、`CLAUDE.md`「モデルの流れ」

福岡都市圏を対象に、土地利用モデルと交通モデルを統合したLUTI（土地利用交通統合）モデルを構築する。
1kmメッシュを居住ゾーン $i$（847個）および従業ゾーン $j$（17個）とする（3.2）。
主体は家計・デベロッパー・土地所有者の3者で、住宅床面積の市場を通じて相互に作用する。
均衡は従業ゾーン別の効用水準 $v_j$ によって記述される。

交通モデルは、通勤の交通手段選択（自動車・鉄道・自転車／徒歩）と、自動車OD交通量の道路網への配分から成る。
両モデルは次の反復（LUTIループ）で結ばれる。

1. 所要時間から手段選択確率と通勤の一般化費用を求め、可処分所得を更新する。
2. 土地利用の均衡を解き、居住ゾーン別・従業ゾーン別の世帯数を得る。
3. 自動車OD交通量を道路網に配分し、混雑後の所要時間を得る。
4. 所要時間を更新して1に戻り、収束するまで繰り返す。

**仮定**

- 1世帯は就業者1人で、通勤は1日1往復とする。
- 家計の異質性は従業地 $j$ のみで表し、所得階層や世帯人数は区別しない。
- 複合財の価格を $p=1$、$\alpha_z+\alpha_a=1$ とする。
- 自転車・鉄道の所要時間は混雑の影響を受けない（自動車のみ混雑を考慮する）。

**単位**: 所得・賃金・通勤費用は千円/月、家賃（付け値地代）は千円/m²/月、床面積はm²、所要時間は分、
自動車交通量は台/日（pcu/日相当）。

### 3.1.2 家計の行動

- 採用日: 2026-09-19
- 根拠: `scripts/Fukuoka_LUTI_model_260617.R`（L.471–538, L.665–676）、`scripts/Fukuoka_modeChoide_260309_copied.R`（手段選択の推定）

**効用最大化.** 従業地 $j$ に勤める家計は、複合財 $z$ と住宅床面積 $a$ から得られる効用

$$U = z^{\alpha_z} a^{\alpha_a} \tag{1}$$

を、予算制約

$$z + r\,a = Y_{ij},\qquad Y_{ij}=\max(\omega_j - c_{ij},\,0) \tag{2}$$

のもとで最大化する。ここで $r$ は家賃（千円/m²/月）、$\omega_j$ は従業地 $j$ の賃金、$c_{ij}$ は居住地 $i$ から従業地 $j$ への
通勤費用、$Y_{ij}$ は可処分所得である。床面積需要と間接効用は次のとおりである。

$$a_{ij}=\frac{\alpha_a Y_{ij}}{r_{ij}} \tag{3}$$

$$v_{ij}=\frac{\alpha_0\,Y_{ij}}{r_{ij}^{\alpha_a}},\qquad \alpha_0=\alpha_z^{\alpha_z}\alpha_a^{\alpha_a} \tag{4}$$

従業地 $j$ の家計の効用が居住地によらず均衡水準 $v_j$ に等しいという条件から、居住地 $i$ における付け値地代（家賃）は

$$r_{ij}=\left(\frac{\alpha_0\,Y_{ij}}{v_j}\right)^{1/\alpha_a} \tag{5}$$

となる。$Y_{ij}=0$ のとき、そのペアには立地しない（立地確率を0とする）。

**通勤の交通手段選択.** 手段は自転車・徒歩（bike）、自動車（car）、鉄道（rail）の3つとし、多項ロジットモデルで表す。

$$V_{bike}=\beta_t T_{bike},\quad V_{car}=\beta_t T_{car}+\mathrm{ASC}_{car}+\beta_p\,\frac{P^{park}_i+P^{park}_j}{2},\quad V_{rail}=\beta_t T_{rail}+\mathrm{ASC}_{rail} \tag{6}$$

$$P_m=\frac{\exp V_m}{\sum_{m'}\exp V_{m'}} \tag{7}$$

$T$ は所要時間（分）である。自動車は道路網の混雑後の所要時間（3.1.5）、自転車・徒歩は道路網上の時速15km・混雑なしでの所要時間、
鉄道は鉄道網（鉄道60km/h、地下鉄40km/h、メッシュ重心・駅間のアクセスリンク5km/h、混雑なし）上の所要時間を用いる。
駐車料金 $P^{park}$ は、ゾーンの地価の3%を年間の地代とし、駐車1台あたり12.5m²として日額（円/日）に換算した値である。

通勤の一般化費用は、選択確率で重み付けした一般化時間

$$\bar T_{ij}=\frac{\sum_m P_m V_m}{\beta_t}\ (\text{分}),\qquad c_{ij}=1.6\,\bar T_{ij}\ (\text{千円/月}) \tag{8}$$

で与える。

**手段選択モデルの推定.** 第5回北部九州圏パーソントリップ調査（平成29年）の通勤目的のOD交通量を用い、
手段を「徒歩・自転車」「自動車・自動二輪車」「鉄道・バス」の3つに集約して、最尤法（BFGS）で $\beta_t,\mathrm{ASC}_{car},\mathrm{ASC}_{rail},\beta_p$ を推定した。
PTゾーンごとに代表メッシュを定め、代表メッシュ間のネットワーク上の所要時間を説明変数に用いた。
推定結果は次のとおりである。

| 変数 | 推定値 | 標準誤差 | z値 |
|---|---:|---:|---:|
| 所要時間 $\beta_t$（/分） | −0.05255 | 1.81×10⁻⁴ | −291 |
| 自動車定数 $\mathrm{ASC}_{car}$ | 1.1177 | 4.33×10⁻³ | 258 |
| 鉄道定数 $\mathrm{ASC}_{rail}$ | −0.2702 | 3.38×10⁻³ | −80 |
| 駐車料金 $\beta_p$（/円/日） | −0.002437 | 5.82×10⁻⁶ | −419 |

### 3.1.3 デベロッパーの行動

- 採用日: 2026-09-19
- 根拠: `scripts/Fukuoka_LUTI_model_260617.R`（L.481–499）

デベロッパーは宅地 $G_i$ に建設投入 $K$ を加えて床面積 $F$ を供給する。生産関数を

$$F=\gamma_0\,K^{\gamma_1}G_i^{\,1-\gamma_1} \tag{9}$$

とし、建設投入の単位費用を $k_i$ とする。ゾーン $i$ の平均家賃を $\bar r_i$ として利潤を最大化すると、床面積の供給量は

$$F_i=\gamma_0\left(\frac{\bar r_i\,\gamma_0\gamma_1}{k_i}\right)^{\frac{\gamma_1}{1-\gamma_1}}G_i \tag{10}$$

となる。デベロッパーが土地に対して支払える付け値地代（千円/m²/月）は、建蔽率 $\phi$ を乗じて

$$rg_i=\phi\,(1-\gamma_1)\,(\bar r_i\gamma_0)^{\frac{1}{1-\gamma_1}}\left(\frac{\gamma_1}{k_i}\right)^{\frac{\gamma_1}{1-\gamma_1}} \tag{11}$$

とする。

**床面積の従業地別配分.** ゾーン $i$ の床面積のうち従業地 $j$ の家計に貸される割合を、付け値地代（式5）に対するロジットで与える。

$$P(j\mid i)=\frac{\exp(\theta_H r_{ij})}{\sum_{j'}\exp(\theta_H r_{ij'})} \tag{12}$$

ゾーン $i$ の平均家賃（帰属地代）は

$$\bar r_i=\sum_j r_{ij}\,P(j\mid i) \tag{13}$$

である。

### 3.1.4 土地所有者の行動

- 採用日: 2026-09-19
- 根拠: `scripts/Fukuoka_LUTI_model_260617.R`（L.495–496）

土地所有者は、ゾーン $i$ の可住地 $G0_i$ を、デベロッパーの付け値地代 $rg_i$ と農地地代 $rr_a$ の差に応じて宅地に転用する。
宅地面積は

$$G_i=G0_i\;\frac{\exp\{\theta_L(rg_i-rr_a)\}}{1+\exp\{\theta_L(rg_i-rr_a)\}}\;\phi_{pub}\,\phi \tag{14}$$

で与える。$\theta_L$ は転用のしやすさを表すパラメータである。

### 3.1.5 市場均衡条件

- 採用日: 2026-09-19
- 根拠: `scripts/Fukuoka_LUTI_model_260617.R`（L.517–550, L.554–602, L.800–878）

**土地利用の均衡.** ゾーン $i$ で従業地 $j$ の家計に供給される床面積は

$$A^S_{ij}=F_i\,P(j\mid i) \tag{15}$$

であり、床面積の需給が一致するとき、居住地 $i$・従業地 $j$ の世帯数は

$$l_{ij}=\frac{A^S_{ij}}{a_{ij}} \tag{16}$$

となる。従業地 $j$ に勤める世帯数は従業者数 $\hat L_j$ に一致しなければならない。

$$\sum_i l_{ij}=\hat L_j\qquad (j=1,\dots,17) \tag{17}$$

未知数は従業ゾーン別の均衡効用 $v_j$（17個）、方程式も17本であり、$\log v_j$ について
非線形連立方程式ソルバー（`nleqslv`、`dbldog`法、許容誤差 $10^{-8}$）で解く。初期値は $v_j=270$ とする。

**道路交通の配分.** 自動車OD交通量を $l_{ij}P^{car}_{ij}$（1世帯1日1往復）とし、道路網（OpenStreetMap由来）に利用者均衡配分
（`cppRouting`、`bfw`、収束判定 $10^{-2}$）で配分する。リンク所要時間はBPR関数

$$t = t_0\left[1+\alpha\left(\frac{x}{C}\right)^{\beta}\right],\qquad \alpha=0.48,\ \beta=2.89 \tag{18}$$

とする（山田・松井, 1998）。$t_0$ は自由流所要時間、$x$ は交通量、$C$ は容量である。
容量は道路種別ごとに設定した値（pcu/時、国土技術政策総合研究所の資料）を、ピーク時と日交通量の比（K値0.1）で日単位に換算して用いる。

**LUTIループ.** 配分後のリンク所要時間から得た所要時間行列を、旧行列との重み0.5の逐次平均（MSA）で更新し、
手段選択（式6–8）→ 土地利用の均衡（式17）→ 道路配分を繰り返す。更新前後の所要時間行列の差の二乗和が100未満になれば収束とする。
鉄道は混雑を考慮せず、収束後の最終状態に対して鉄道OD交通量（$l_{ij}P^{rail}_{ij}$）を1回だけ配分する。

**対象地域.** 福岡都市雇用圏（コード40130）と、その境界に100mのバッファを加えた範囲に含まれる1kmメッシュを対象とする。
このうち、可住地が1kmメッシュの面積の10%以上あるものだけを居住可能なメッシュとする。
可住地は、国土数値情報の土地利用細分メッシュ（100mメッシュ）のうち、森林・荒地・河川地及び湖沼・海水域・海浜・その他用地を除く土地利用種別とする。
