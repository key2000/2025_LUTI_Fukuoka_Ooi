# paper/ — 論文に載せると決めたことだけを置く場所

**ここに置くのは、論文に載せると決めたもの（採用済み）だけ。** 採用を判定するのはユーザー本人であり、
Claudeが「良さそう」と判断して書き込むことはしない。試行錯誤・未確定の方針・TODO・先生とのやり取りは
`project_log/` に置く（特に `project_log/paper-direction/`）。

| 内容 | 置き場所 |
|---|---|
| 試行、途中経過、不採用になった案、未確定の方針、TODO、先生とのやり取り | `project_log/`（論文まわりの方針メモは `project_log/paper-direction/`） |
| ユーザーが「論文に採用する」と決めた式・パラメータ・データ・図・数値 | **`paper/`（このフォルダ）** |

## 書き込みの流れ

1. 試行や方針は、まず `project_log/` に記録する。
2. ユーザーが「これを論文に採用」と言ったときだけ、スキル `promote-to-paper`
   （`.claude/skills/promote-to-paper/`）で `paper/` の該当節へ昇格する。
3. 昇格した試行の `meta.yml` には `paper: adopted` と `paper_ref:` を記録する（未採用は `paper: none`）。
4. `paper/**` への書き込みは `.claude/settings.json` の権限設定で毎回確認が出る。承認は採用の確認を兼ねる。

## ファイル構成

採用内容は、論文の章立てに対応する次の2ファイルに、節見出しごとに追記する（最初の採用時に作成する）。

- `ch3_method.md` — 第3章 研究方法
- `ch4_results.md` — 第4章 分析結果

第1・2・5・6章は、必要になった時点で `chN_名前.md` を同じ形式で追加する。

### 節構成（論文の目次）

- 第3章 研究方法: 3.1 構築するモデル（3.1.1 モデルの概要と仮定／3.1.2 家計の行動／3.1.3 デベロッパーの行動／
  3.1.4 土地所有者の行動／3.1.5 市場均衡条件）、3.2 分析対象、3.3 使用データとキャリブレーション、
  3.4 シナリオの内容、3.5 評価指標
- 第4章 分析結果: 4.1 モデルの再現性検証、4.2 シナリオ分析の結果

## 採用内容の書き方

各節の下に、採用した項目ごとに次の形式で書く。**未確定の項目（要確認・値が未記録など）は書かない**。
確定しきれていない部分がある場合は、確定した部分だけを書き、残りは `project_log/paper-direction/` に置く。

```markdown
### 3.3 使用データとキャリブレーション

#### 5パラメータの較正結果
- 採用日: 2026-MM-DD
- 根拠: `project_log/calibration/01_baseline-5param-ga/`
- 内容: （式・値・図のパス・手法の説明など、論文にそのまま使える形で）
```

- 数値や図は、根拠の試行にあるものと一致させる。図は `project_log/` のPNGへのパスで参照する
  （コピーしない。論文用に作り直したときだけ `paper/figures/` に置く）。
- 採用を取り消す・差し替えるときは、該当項目を書き換え（または削除）し、元の試行の `meta.yml` の
  `paper:` も更新する（詳細は `promote-to-paper` スキル）。

## 素材の下書き

論文の第3章・第4章に載せる可能性のある素材（未確定・TODOを含む）の下書きは
`project_log/paper-direction/ch3_ch4_materials.md`。ここから、採用が決まった項目だけを上の手順で昇格する。
